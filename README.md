# [Projeto EasyCreche](https://easycreche.lsnegrello.com.br/auth/login)

## Objetivo:

- Projeto para auxiliar as creches com a organização, cadastros e registros relacionados aos alunos.

## Tecnologias Envolvidas:

- Backend: Desenvolvido em Laravel com Docker, utilizando:
  - Sanctum para autorização.
  - Banco de dados PostgreSQL.
  - Cache com Redis.
 
- Frontend: Desenvolvido em Angular, utilizando:
  - Biblioteca do PrimeNG
